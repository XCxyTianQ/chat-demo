# 余烬与墨 · Ember & Ink（v1，已被 Astra 取代）

> 当前视觉是「群星 Astra」，见 [DESIGN-ASTRA.md](DESIGN-ASTRA.md)。本文件保留最初的纸墨方案，
> 令牌名（`--rp-*`、`--char-*`）与部分排版规则仍被沿用。

角色扮演对话平台（非工程用途）。引擎沿用 chat-demo：SSE 流式、消息分支、附件、Markdown。
本层把「助手」换成「角色」：角色卡 + 用户人格 + 场景化排版。

## 一、定位与气质

深夜书房的气质：纸、墨、烛火。不是工具，是一处可以坐下来的地方。

- **排版像小说，不像工单**：角色的话是剧本正文（无气泡、左侧书脊线 + 角色名小字），
  用户的话是右侧窄气泡（像批注）。留白大，行距宽。
- **每个角色有自己的颜色**：角色卡带 `accent` 色相，进入对话后整个界面的强调色、
  背景光晕、书脊线都随之变化。这是整套视觉的「生成性」来源——同一个界面，
  和不同的人说话是不同的气氛。
- **质感来自纸与光**：噪点颗粒、暗角、缓慢流动的背景光斑；不用照片、不用拟物纹理图片。
- **动效克制**：只用 opacity/transform，180–260ms；尊重 prefers-reduced-motion。

## 二、设计令牌（已在 src/styles/rp-theme.css 落地）

深色（默认）：
- bg `#131218` / surface `#1A1922` / raised `#232231`
- 纸色文字 `#F1EBE0` / 次要 `#B4ADA1` / 弱 `#7B766D`
- 余烬强调 `#E3A06A`（hover `#F0B583`）
- 分隔 `rgba(241,235,224,.08)`，卡片描边 `rgba(241,235,224,.10)`
- 阴影只用于浮层；正文区靠明度与线条区分层次

浅色：
- paper `#F5F0E6` / surface `#FFFCF5` / raised `#FFFFFF`
- 墨 `#241F1B` / 次 `#5C554C` / 弱 `#8A8378`
- 强调 `#A85A28`

字体：
- 标题、角色名、书名号类文案：`var(--rp-font-display)` → Noto Serif CJK SC（本机已装）
- 氛围旁白、引文：`var(--rp-font-quote)` → KaiT-SC 楷体
- 正文与控件：系统无衬线

## 三、信息架构

```
┌──┬──────────────┬──────────────────────────────┐
│竖│ 角色 / 会话   │ 场景头（角色横幅）            │
│栏│   · 角色卡列表 │ 消息流（剧本排版）            │
│  │   · 最近会话   │ 输入区                        │
└──┴──────────────┴──────────────────────────────┘
```

- **竖栏**（64px）：角色库 / 会话 / 设置，三个入口 + 当前用户人格头像。
- **侧栏**（296px）：上半是「角色」网格卡（头像 + 名字 + 一句话），点击进入该角色的新会话；
  下半是「最近对话」，按更新时间列出会话，带角色头像。
- **主区**：
  - 没有选中会话时 = 角色画廊（大卡片，悬停浮起，展示标签与开场白首句）
  - 选中会话时 = 场景头 + 消息流 + 输入区
- 移动端：竖栏与侧栏合并成抽屉，场景头收成 48px 顶栏。

## 四、角色卡数据模型

见 `src/services/characters/types.ts`。核心字段（与 SillyTavern V2 角色卡对齐，便于导入导出）：

`name` `avatar?` `accent`(色相) `tagline`(一句话) `tags[]`
`description` `personality` `scenario` `firstMessage` `exampleDialogues`
`systemPrompt?`(角色私有补充) `creatorNotes?`

用户人格：`name` `avatar?` `description`，全局唯一一份。

## 五、约定（给并行开发者）

- **界面文案简体中文，直接写在各自模块的 `strings.ts`**，不要改 `src/i18n/zh.ts`
  和 `en.ts`（那两份属于上游，避免冲突）。
- **只改自己名下的文件**，CSS 用各自的 `*.module.css`；公共令牌在
  `src/styles/rp-theme.css`（由 Lead 维护，禁止改动）。
- 视觉一律走令牌，不写死颜色；角色色用 `var(--char-accent)`。
- 图标用 `src/components/base/icons.tsx` 现成的，缺的话在
  `src/components/base/rpIcons.tsx` 里加（Lead 维护，按需追加）。
- 提交前跑 `pnpm build`（本机已验证可用）；并发构建偶发 `rm -rf dist` 冲突就重试一次。
