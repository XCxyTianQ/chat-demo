# 群星 · Astra

「夜话」的第二版视觉：把对话放进一座深夜的观测舱。角色是星，对话是观测记录。

## 气质

不是聊天气泡，是天文台的仪器面板：深空、星云、刻度环、等宽编号、玻璃舱。

- **底**：近黑深空 `#05060c`，角色色相的星云在左上缓慢呼吸，三层星点视差闪烁，偶尔一颗流星。
- **结构**：星盘刻度环（Astrolabe）在会话区背后极慢转动（180s/120s 反向），透明度很低，只提供「仪器感」。
- **材质**：玻璃（`--rp-surface` 半透明 + `backdrop-filter: blur(18px)`）+ 1px 星光描边 + 极细噪点。
- **字体**：标题、角色名、正文尾巴用 Noto Serif；编号/坐标/状态用等宽体，大写 + 0.18em 字距。
- **强调色**：星辉金 `--rp-ember`（#e6d7a8）用于交互；角色色相 `--char-accent` 用于每个角色自己的星云、星座连线与光晕。
- 浅色主题是「日光观测台」：蓝图白底、墨蓝字、细蓝线。

## 星表

每个角色由名字确定性派生一组只读的星表信息（`starDesignation(name)`）：

```
HD 48213 · 12h34m +08°12′
```

出现在：画廊卡片右上角、会话页头的第二行、角色编辑器预览区。

## 布局

```
┌────┬──────────────┬────────────────────────────┬──────────────┐
│竖栏 │ 星图 / 观测记录│  观测舱：页头 + 记录流 + 控制台 │ 剧本面板(可折叠)│
│72  │ 300          │  居中 820                    │ 300          │
└────┴──────────────┴────────────────────────────┴──────────────┘
```

- **竖栏**：竖排文字标签（`writing-mode: vertical-rl`），「星图 / 记录 / 观测者」+ 底部设置。
- **页头（playbill）**：小字 `ASTRA · 观测记录 03`、大号角色名（clamp 40–56px）、星座 SVG 作为名字背后的低透明装饰、标签行 `HD 48213 · 12h34m +08°12′ · 江湖 / 侠气`、右侧两枚仪表按钮（角色档案 / 新的一段）。
- **记录流**：每条 AI 记录左侧一条 1px 星光竖线，顶端一枚星点节点，上方等宽小字 `RECEIVED · 23:12`；正文 serif 16px/1.95；段间 14px。用户输入是右对齐的玻璃「上行卡」，左上角一枚 4px 星点 + `UPLINK` 标签。
- **幕次分隔**：`— 观测记录 01 · 23:11 —`，两侧发丝线，中间星点。
- **控制台（输入）**：玻璃舱底，左侧竖排 `TRANSMIT`，中间 textarea，底部一行开关（深度思考 / 联网 / 附件 / 语音）与右侧发射按钮（含脉冲光环）。上方一行状态：`LINK STABLE · deepseek-flash`。

## 约束

- 全 SVG/CSS，不引入图片与新依赖。
- 动画只用 transform/opacity；尊重 prefers-reduced-motion。
- 文字对比度：所有正文都压在 `--rp-bg` 或玻璃面板上，不允许直接躺在星云上。
- 文案仍简体中文；编号类英文（ASTRA / RECEIVED / UPLINK / LINK STABLE）作为视觉装置。
